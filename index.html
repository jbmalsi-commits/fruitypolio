Problem-Solving & Cybersecurity Case Studies

Documented troubleshooting logs and defensive security practices

Troubleshooting Case #1: Wi-Fi Connectivity Failure

  • Problem: Workstation cannot connect to the wireless network after a driver update.
  • Possible Causes: Corrupted or incompatible Wi-Fi driver, disabled WLAN AutoConfig service, or incorrect IP configuration.
  • Diagnostic Procedure: Checked Wi-Fi status and Device Manager, refreshed the IP address using ipconfig /release and ipconfig /renew, and verified WLAN AutoConfig.
  • Solution: Rolled back the wireless adapter driver, restarted the workstation, and flushed the DNS cache using ipconfig /flushdns.
  • Lesson Learned: Verify driver compatibility before major OS updates and test network connectivity afterward.

Cybersecurity Case: SQL Injection Prevention

  • Vulnerability: SQL Injection in user login authentication form.
  • Risk: Unauthorized database access, data leakage, and administrative privilege escalation.
  • Prevention Strategy: Implementation of Prepared Statements and Parameterized Queries using PDO in PHP/Python.
  • Security Practice: Input sanitization, principle of least privilege for database accounts, and multi-factor authentication (MFA).
